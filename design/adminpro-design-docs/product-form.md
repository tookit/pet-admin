# 商品表单（Catalog · Product Form）

> 页面类型：新建 / 编辑侧拉表单
> 推荐组件：`DrawerForm`、`ProFormText`、`ProFormTextArea`、`ProFormSelect`、`ProFormTreeSelect`、`EditableProTable`、`Upload.Dragger`、`Switch`
> 截图：`../product-form.png`

---

## 1. 页面目标

在商品列表页通过侧拉抽屉快速新建或编辑商品，覆盖基本信息、分类标签、价格阶梯、媒体与发布状态五个核心区块。表单宽度固定 640px，保持桌面端信息密度与可读性的平衡。

---

## 2. 页面结构

```txt
DrawerForm（width=640，destroyOnClose）
├── Header
│   └── 编辑商品 · {商品名}  |  新建商品
├── Body（垂直区块，区块间距 24px）
│   ├── 01 基本信息
│   ├── 02 分类与标签
│   ├── 03 价格与 MOQ
│   ├── 04 媒体
│   └── 05 发布
└── Footer
    ├── 删除商品（danger text）
    └── 取消 | 保存修改（primary）
```

---

## 3. 区块 01：基本信息

| 字段 | 组件 | 规则 |
| ---- | ---- | ---- |
| SKU * | `Input` | 必填；全站唯一；建议大写 + 数字 + 连字符，如 `AQ-HT-300W-01`；使用等宽字体 |
| 商品名称 * | `Input` | 必填；长度 2–120 字符 |
| Slug | `Input` | 留空时由名称自动生成；仅允许小写字母、数字、连字符；用于前台 URL |
| 类型 | `Select` | 选项：`Physical` / `Virtual` / `Digital` / `Service`；默认 `Physical` |
| 简短描述 | `TextArea`（rows=3） | 选填；最大 500 字符；右下角显示 `28 / 500` 计数器 |

布局：

```txt
[SKU *]              [商品名称 *]
[Slug]               [类型]
[简短描述                      ]
```

说明文案（区块标题下方）：`SKU 与名称为必填；Slug 留空由名称自动生成。`

---

## 4. 区块 02：分类与标签

| 字段 | 组件 | 规则 |
| ---- | ---- | ---- |
| 分类 | `TreeSelect` multiple | 可多选；用于前台目录筛选 |
| 标签 | 自定义输入标签 | Enter 添加；点击 × 删除；用于检索与 OEM 标记 |

布局：

```txt
分类    [水族器材 ×] [加热设备 ×] [选择分类...]
标签    [CE 认证 ×] [OEM ×] [输入后回车...]
```

说明文案：`分类可多选，用于前台目录筛选；标签用于检索与 OEM 标记。`

---

## 5. 区块 03：价格与 MOQ

### 5.1 表格列

| 列 | 组件 | 规则 |
| ---- | ---- | ---- |
| 最小起订量 * | `InputNumber`（min=1） | 整数；按升序排列；首行即商品 MOQ |
| 单价 * | `InputNumber`（min=0.01，precision=2） | 货币格式，右对齐，tabular-nums |
| 币种 * | `Select` | `USD` / `CNY` / `EUR` / `GBP`；默认 `USD` |
| 标签（选填） | `Input` | 如「批发价」「托盘价」「整柜价」 |
| 操作 | 文字按钮 | 编辑 / 删除 |

### 5.2 交互

- 初始空态显示占位行提示：`点击「新增阶梯」添加第一个批发价档位`。
- 至少保留一行完整的价格阶梯，否则保存时表单校验失败。
- 新增阶梯默认 `MOQ = 上一行 + 100`，单价默认与上一行相同，便于快速调整。
- 保存前自动按 MOQ 升序排序；若出现重复 MOQ，高亮重复行并提示。
- 删除最后一行时给出二次确认。

布局：

```txt
说明：阶梯按起订量升序；系统取最小起订量作为商品 MOQ，买家端按数量自动匹配档位。

| 最小起订量 | 单价    | 币种 | 标签   | 操作 |
| 100        | $4.20   | USD  | 批发价 | 编辑 |
| 500        | $3.65   | USD  | 托盘价 | 编辑 |
| 1,000      | $3.20   | USD  | 整柜价 | 编辑 |

[+ 新增阶梯]
```

## 6. 区块 04：媒体

### 6.1 上传区

使用 `Upload.Dragger`：

```txt
┌────────────────────────────────────────┐
│           ↑                            │
│   将文件拖拽到此处，或 点击上传          │
│   JPG / PNG / WebP · ≤ 10MB · 可多选   │
└────────────────────────────────────────┘
```

- 上传中显示进度条；失败给出错误提示。
- 支持从媒体库选择：`[从媒体库选择]` 文字按钮。

### 6.2 缩略图列表

- 网格展示，每项 80×80px，圆角 4px，白底。
- 首图（Featured）左上角显示「主图」薄荷绿徽标。
- 每张图片悬浮显示操作栏：`设为主图`（StarOutlined）、`删除`。
- 非主图下方显示「设为主图」文字按钮。

## 7. 区块 05：发布

| 字段 | 组件 | 规则 |
| ---- | ---- | ---- |
| 状态 | `Select` | `Active` / `Draft` / `Archived` / `Discontinued`；默认 `Draft` |
| 推荐（Featured） | `Switch` | 开启后商品进入首页 / 专题推荐位 |

说明文案：`草稿不对外展示；设为「在售」后进入前台目录。`

---

## 8. 校验与交互规则

1. SKU、商品名称为必填。
2. SKU 提交前校验唯一性，重复时提示 `该 SKU 已存在`。
3. Slug 若填写，仅允许 `a-z0-9-`，且不能以连字符开头或结尾。
4. 价格阶梯至少有一行，且最小起订量 ≥ 1、单价 > 0。
5. 价格阶梯按 MOQ 升序排列；重复 MOQ 不允许保存。
6. 媒体图片总大小 ≤ 50MB；单张 ≤ 10MB。
7. 删除商品按钮位于页脚左侧，红色文字，点击后二次确认。
8. 保存成功 → `message.success('商品已保存')` → 关闭 Drawer → 刷新商品列表。

---

## 9. 空态与 Loading

- 新建表单所有字段为默认值，价格阶梯为空。
- 编辑表单加载时显示 `Skeleton` 占位，加载失败给出 Alert + 重试。
- 保存按钮在提交时显示 `loading` 并禁用。
