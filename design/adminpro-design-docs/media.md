# 媒体库（Media Library）

> 页面类型：资源管理
> 推荐组件：`PageContainer`、`Upload.Dragger`、`Image.PreviewGroup`、`Tree`/自定义文件夹列表、`Card`、`Checkbox`、`Popconfirm`
> 截图：`../media.png`

---

## 1. 页面目标

集中管理商品图、分类封面、认证文件与工厂实拍；核心体验是**拖拽即传**与**使用位置可追溯**。

---

## 2. 页面结构

```txt
PageContainer
├── 左侧文件夹面板（190px）
│   ├── 全部文件 1,208
│   ├── 商品图 864
│   ├── 分类封面 42
│   ├── 认证文件 96
│   ├── 工厂实拍 206
│   └── + 新建文件夹（主色）
└── 右侧主区
    ├── 工具行（标题 | 搜索 / 网格 / 列表切换）
    ├── ★ 可拖拽上传区（Drgzone）
    └── 媒体网格（5 列）
```

---

## 3. 可拖拽上传区（核心交互）

`Upload.Dragger` 定制样式：

```txt
边框：1.5px dashed --primary-300，背景 --primary-50，圆角 6px
hover / dragover：边框 --primary-500，背景 --primary-100
图标：上传 arrow 30px，主色描边
文案：点击上传 或将文件拖拽到此处
提示：支持 JPG / PNG / WebP / PDF · 单文件 ≤ 10MB · 可多选 · 拖入后自动进入上传队列
```

行为：

- 拖入即上传，成功后新卡片置顶插入网格，带「上传成功 ✓」金色角标
- 上传中显示进度（Progress 环形，置于卡片缩略图上）
- 超限 / 类型不符 → `message.error`
- 点击虚线框唤起文件选择器（可多选）

---

## 4. 文件夹面板

```txt
项：15px folder 图标 + 名称 + 右侧数量（11px 灰）
选中：--primary-50 底 + --primary-700 文字 + 600 字重
「新建文件夹」：主色文字项，点击弹 ModalForm 命名
```

---

## 5. 媒体卡片（网格 5 列）

```txt
缩略图（84px，渐变浅底占位）：
  - 悬浮遮罩（rgba(39,36,37,.48)）：预览 / 编辑 / 删除（白字 12px）
  - 左上 checkbox（批量选择）
  - PDF 等非图片用文档图标
元信息：
  - 文件名：mono 11.5px，超长省略
  - 大小 · 尺寸：10.5px 灰
  - 使用位置标签（usage tag）
```

使用位置标签示例：

| 标签 | 颜色 |
| ---- | ---- |
| 已用于 1 个 SKU | mint |
| 分类封面 · 宠物窝具 | mint |
| About Us 页 | mint |
| 认证 30 天内到期 | **gold（待处理语义）** |

---

## 6. 操作

- 预览：`Image.PreviewGroup` 大图预览
- 编辑：ModalForm 改文件名 / alt 文本 / 所属文件夹
- 删除：Popconfirm；若文件仍被 SKU 引用，提示引用数并要求二次确认
- 批量：选中后工具行出现「移动到… / 删除」
- 列表模式：切为 ProTable（文件名 / 类型 / 大小 / 使用位置 / 上传时间 / 操作）

---

## 7. 上传队列与错误

- 上传中：卡片置顶 + 环形进度
- 失败：红色「重试」角标，点击重传
- 全部完成：`message.success('3 个文件上传成功')`

---

## 8. 响应式

| Tablet 768–1199 | 3–4 列 |
| Mobile <768 | 2 列；文件夹面板收起为下拉 |
